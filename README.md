# Andén Alerta Cartagena 

**Andén Alerta Cartagena** es una página web desarrollada por estudiantes de la **Corporación Universitaria Rafael Núñez**, como una iniciativa para contribuir al mejoramiento de la movilidad peatonal en la ciudad de Cartagena.

##  Descripción del proyecto

El proyecto busca facilitar el reporte y seguimiento de problemas que afectan el estado de los andenes y la movilidad de los peatones, como huecos, deterioros, obstáculos y rampas dañadas.

A través de la plataforma, los ciudadanos pueden registrar reportes y consultar la información, mientras que los administradores pueden gestionar y dar seguimiento a los casos registrados.

##  Objetivo

Promover la participación ciudadana y ayudar a identificar problemas en la infraestructura peatonal de Cartagena, facilitando su registro y seguimiento mediante una plataforma web.

##  Tecnologías utilizadas

- **PHP:** funcionamiento y lógica del sistema.
- **HTML:** estructura de las páginas.
- **CSS:** diseño y adaptación a diferentes dispositivos.
- **JavaScript:** interactividad y eventos.
- **JSON:** almacenamiento local de información.
- **Git y GitHub:** control de versiones y trabajo colaborativo.

## ⚙️ Instalación y ejecución

Para ejecutar el proyecto localmente se necesita tener instalado [XAMPP](https://www.apachefriends.org/es/index.html).

1. Descargar o clonar este repositorio.
2. Colocar la carpeta `AndenAlertaCartagena` dentro de `C:\xampp\htdocs\`.
3. Iniciar Apache desde el panel de control de XAMPP.
4. Abrir el navegador e ingresar a:

   `http://localhost/AndenAlertaCartagena/`
